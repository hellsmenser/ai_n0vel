# Bundled theme fonts

These font files are bundled with the Ren'Py client so every theme has the same
Cyrillic-capable typography on desktop and web builds. The theme manifests use
paths relative to the Ren'Py `game` directory (`gui/themes/fonts/...`).

| Family | Theme use | Upstream |
| --- | --- | --- |
| Fira Sans (Regular, Bold) | default, modern muted | <https://github.com/google/fonts/tree/main/ofl/firasans> |
| PT Serif (Regular, Bold) | literary, romantic | <https://github.com/google/fonts/tree/main/ofl/ptserif> |
| Philosopher (Regular, Bold) | Lovecraft biopunk, high fantasy | <https://github.com/google/fonts/tree/main/ofl/philosopher> |
| Play (Regular, Bold) | science fiction | <https://github.com/google/fonts/tree/main/ofl/play> |

Each family directory contains the exact `OFL.txt` distributed with that family
in the official Google Fonts repository. All files were retrieved from the
`main` branch on 2026-10-21. The fonts are licensed under the SIL Open Font
License 1.1; see the adjacent license before modifying or redistributing them.
